SHM M&E Platform — install package
==================================

CONTENTS
  SHM M&E Platform (standalone).html   Ready to run. Double-click to open in any
                                       browser. Works fully offline: no install,
                                       no server, no network calls.
  SHM Platform v2.dc.html              Editable source of the same prototype.
  support.js                           Runtime + mock data used by the source file.

TO RUN
  Open "SHM M&E Platform (standalone).html" in Chrome, Edge, Safari or Firefox.
  That single file contains everything.

TO HOST IT (shared link)
  Upload the standalone file to any static host (SharePoint, Google Drive,
  Netlify Drop, an internal web folder). No build step required.

TO EDIT
  Keep "SHM Platform v2.dc.html" and "support.js" in the SAME folder, then open
  the .dc.html file. Editing the standalone file directly is not recommended.

NOTES
  Data is mock data held in the page; nothing persists between sessions.
  The Arabic (عربي) toggle is intentionally disabled in this version.
